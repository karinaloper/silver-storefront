# Plata · Joyería de Taxco

Sitio de Plata, una marca de joyería artesanal en plata .925 de Taxco, Guerrero, México. La página presenta la colección de aretes, anillos y pulseras, cuenta el origen de las piezas y reúne consejos para cuidar la plata.

[Visitar el sitio](https://karinaloper.github.io/silver-storefront/)

## Ver el sitio en tu equipo

Clona el repositorio y abre `index.html` en tu navegador. También puedes descargarlo desde **Code → Download ZIP** y abrir el archivo después de extraerlo.

```sh
git clone https://github.com/karinaloper/silver-storefront.git
cd silver-storefront
```

El sitio usa HTML y CSS. Las fotos editoriales y las tipografías se cargan desde Unsplash y Google Fonts.

## Editar y publicar

- [index.html](index.html) contiene los textos, las secciones y los estilos de la página.
- [favicon.png](favicon.png) es el icono que aparece en la pestaña del navegador.

GitHub Pages publica el sitio desde la raíz de la rama `main`. Los cambios en esa rama se despliegan automáticamente.
